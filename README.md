# Predictive Modeling Using Machine Learning

## Objective
Build a machine learning model to predict outcomes based on data.

## Algorithm Used
Random Forest Classifier

## Dataset
Titanic Dataset

## Features Used
- Passenger Class
- Gender
- Age
- Fare

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Classification Report

## Result
The model achieved approximately 84% accuracy.

## Conclusion
The Random Forest model successfully predicted passenger survival outcomes and demonstrated the effectiveness of supervised machine learning.
