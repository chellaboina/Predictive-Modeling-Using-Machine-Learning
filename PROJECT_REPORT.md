# Predictive Modeling Using Machine Learning

## Introduction
Machine Learning is a branch of Artificial Intelligence that enables systems to learn from data and make predictions.

## Objective
To predict passenger survival using the Titanic dataset.

## Dataset
Titanic Dataset containing:
- Passenger Class
- Gender
- Age
- Fare
- Survival Status

## Data Preprocessing
- Missing Age values filled with median.
- Gender converted into numerical values.

## Model Used
Random Forest Classifier

## Train-Test Split
80% Training Data
20% Testing Data

## Evaluation Metrics
1. Accuracy Score
2. Confusion Matrix
3. Classification Report

## Output

Accuracy: 84%

Confusion Matrix:

[[90 15]
 [13 61]]

## Conclusion
The Random Forest model achieved good prediction accuracy and successfully classified survival outcomes.
